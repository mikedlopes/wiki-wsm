# 5S & Visual Workplace — Shop / Yard

**Sort, Set in order, Shine, Standardize, Sustain** for **fabrication**, **staging**, and **material laydown**.

---

## 5S definitions (shop-specific)

| S | Meaning | Fire protection example |
|---|---------|-------------------------|
| 1 — Sort | Remove what’s not needed | Scrap pipe ends, obsolete head samples |
| 2 — Set in order | A place for everything | Color-coded bays by **job** + **system** |
| 3 — Shine | Clean = inspect | Threader chip trays, groover lubrication |
| 4 — Standardize | Visual rules | Shadow boards, max floor stack height |
| 5 — Sustain | Audits + accountability | Weekly 15-min zone owner audit |

---

## Visual factory layout (concept)

```mermaid
flowchart LR
  IN[Inbound receiving] --> QC[QC hold]
  QC --> RAW[Raw stock by size]
  RAW --> FAB[Fabrication cells]
  FAB --> FG[Finished goods staging]
  FG --> LOAD[Truck load-out]
```
