# California Code Compliance Matrix

Practical matrix for California design-build sprinkler projects. Always confirm latest adopted code cycle per jurisdiction.

---

## Compliance matrix

| Requirement area | Primary code / standard | Responsible role | Evidence |
|------------------|-------------------------|------------------|----------|
| Occupancy / hazard classification | CBC + NFPA 13 | Design PE | Calc narrative |
| Hydraulic basis | NFPA 13 | Design | Calc package |
| Seismic bracing | NFPA 13 Ch.18 + CBC | Design + Field | Bracing details + field photos |
| Fire pump (if applicable) | NFPA 20 | Design + Field | Acceptance test reports |
| Inspection and testing | NFPA 25 / AHJ requirements | Field + Service | Test forms |
| Backflow / water supply | Local utility + CFC | PM + Field | Utility approvals |

---

## Permit-to-final workflow

```mermaid
flowchart LR
  PER[Permit submittal] --> APP[Permit approval]
  APP --> FAB[Fabrication / install]
  FAB --> PRE[Pre-test]
  PRE --> AHJ[AHJ inspection]
  AHJ --> FIN[Final signoff]
```
