# Template - Installation & Testing Procedure

## Scope
Installation, flushing, hydrostatic testing, and AHJ readiness for sprinkler scope.

## Pre-Installation Checklist
- [ ] Latest approved drawings onsite
- [ ] Approved submittals match delivered materials
- [ ] Hanger layout verified
- [ ] Safety pre-task plan completed

## Installation Controls
| Control | Requirement |
|---|---|
| Pipe support | NFPA 13 spacing/seismic |
| Head spacing | Per approved layout + obstruction rules |
| Labeling | Zone and system identifiers maintained |

## Testing Sequence
| Step | Test | Requirement | Record |
|---|---|---|---|
| 1 | Flush | Per procedure | Flush report |
| 2 | Hydrostatic | Per NFPA 13 + project spec | Pressure log |
| 3 | Main drain/flow | Per project requirements | Test form |
| 4 | Alarm interface | Verified signals | Commissioning sheet |

## AHJ Readiness
- [ ] Test forms complete
- [ ] Deficiency pre-walk complete
- [ ] Access/escort coordinated
- [ ] As-built redlines current
