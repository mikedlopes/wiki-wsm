# Fire Sprinkler Wiki Content (Wiki.js Git Storage)

Markdown repository for a **C-16 fire protection contractor** wiki: departments, projects, templates, standards, and Lean tools.

## Layout

- `home.md` — Landing dashboard (set as Wiki.js home if desired).
- `departments/` — Accounting (10 pages), Purchasing, Shop, Field, Design, Estimating, Bidding, PM.
- `projects/dashboard.md` — Portfolio hub.
- `projects/TI-2026-045/` — Sample `[project-id]` folder (**TI-2026-045 — Downtown Office Renovation**).
- `templates/` — Six copy-paste ready templates.
- `standards/` — NFPA / criteria hub + design QA checklist.
- `lean-tools/` — Lean overview + 5S.

## Embeds

Replace `REPLACE_*` iframe `src` values with your **Microsoft Planner** embed URLs and **Power BI** embed URLs. Ensure Wiki.js allows **HTML** for trusted groups.

## Mermaid

Enable Mermaid in Wiki.js (**Administration → Rendering → Mermaid**).
