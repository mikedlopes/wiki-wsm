# Fire Sprinkler Wiki Content (Wiki.js Git Storage)

Markdown repository for a **C-16 fire protection contractor** wiki: departments, projects, templates, standards, and Lean tools.

## Layout

- `home.md` — Landing dashboard (set as Wiki.js home if desired).
- `company/` — Start-here wayfinding, about, mission/values, team, org chart, onboarding, operations handbook, resources, and sitemap.
- `departments/` — Accounting (10 pages), Purchasing, Shop, Field, Design, Estimating, Bidding, PM, Service, Safety, HR, IT, Business Development, Executive.
- `processes/` — Company operating processes for design-build and TI delivery.
- `projects/dashboard.md` — Portfolio hub.
- `projects/template-project/` — **Starter folder** to duplicate for each new job (`<ProjectID>`); includes the **SharePoint/file-share** folder tree `/<ProjectID>-<ClientShort>/` with `00_`–`07_` subfolders.
- `projects/TI-2026-045/` — Filled sample job (**TI-2026-045 — Downtown Office Renovation**).
- `templates/` — Six copy-paste ready templates.
- `standards/` — NFPA / criteria hub + California compliance, ITC, QA/QC turnover, substitution policy.
- `lean-tools/` — Lean overview + 5S.

## Embeds

Replace `REPLACE_*` iframe `src` values with your **Microsoft Planner** embed URLs and **Power BI** embed URLs. Ensure Wiki.js allows **HTML** for trusted groups.

## Mermaid

Enable Mermaid in Wiki.js (**Administration → Rendering → Mermaid**).
