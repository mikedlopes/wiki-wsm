# Human Resources — Workforce, Hiring & Development

HR manages recruiting, onboarding, licensing/credential verification, performance development, and retention for office, shop, and field teams.

---

## Workforce planning

| Function | Core roles |
|---------|------------|
| Design-build execution | PM, PE, Designer, Super, Foreman |
| Fabrication and logistics | Shop lead, fabricator, yard/material |
| Service | Coordinator, inspector, service tech |
| Back office | Accounting, HR, admin |

---

## Employee lifecycle

```mermaid
flowchart LR
  R[Recruit] --> O[Offer]
  O --> N[Onboard]
  N --> T[Train / certify]
  T --> P[Performance reviews]
  P --> D[Development path]
```

---

## Compliance checklist

| Item | Frequency |
|------|-----------|
| I-9 / onboarding docs | At hire |
| Drug/background policy | Per policy |
| License / cert verification | At hire + annual |
| Harassment and safety training | Annual or required interval |
