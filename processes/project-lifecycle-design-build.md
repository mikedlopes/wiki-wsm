# Project Lifecycle — California Design-Build Commercial

Standard project lifecycle from pursuit through warranty for full-stack fire protection delivery.

---

## Lifecycle stages

```mermaid
flowchart LR
  BD[Business development] --> EST[Estimating]
  EST --> BID[Bidding]
  BID --> K[Contract + kickoff]
  K --> D[Design + submittals]
  D --> P[Procurement]
  P --> S[Shop fabrication]
  S --> F[Field install]
  F --> T[Testing & commissioning]
  T --> C[Closeout]
  C --> W[Warranty / service]
```

---

## Stage gates

| Stage | Gate deliverable |
|------|------------------|
| Kickoff | Budget, schedule baseline, risk register |
| Design release | Approved submittals + IFC package |
| Install start | Material availability + site readiness |
| Test & inspect | Pre-functional checklist complete |
| Closeout | As-builts, warranties, owner training |
