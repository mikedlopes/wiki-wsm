# Onboarding Home

Start here for all new office, shop, and field hires.

## 30-60-90 onboarding path

| Window | Focus | Deliverable |
|-------|-------|-------------|
| First 30 days | Safety, systems access, role expectations | Completed checklists + mentor assigned |
| Days 31-60 | Process fluency and independent task execution | First independent workflow completed |
| Days 61-90 | Performance baseline + development plan | 90-day review + growth plan |
