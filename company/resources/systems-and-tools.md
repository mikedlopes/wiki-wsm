# Systems & Tools

Single reference for company software stack and ownership.

---

## Core tool map

| Tool | Purpose | Owner |
|------|---------|-------|
| ERP/accounting platform | AP/AR, job cost, close | Accounting |
| PM platform (Procore/ACC/etc.) | RFIs, submittals, docs, issues | PM |
| BIM/design tools | Design and coordination | Design |
| Microsoft 365 + Planner | Communication and tasking | IT/Admin |
| Power BI | KPI reporting and dashboards | Finance + IT |

---

## Tool governance

| Rule | Standard |
|------|----------|
| Source of truth defined | One owner per data object |
| Access changes | Manager-approved |
| Offboarding | Access removed same day |
| Naming conventions | Company standard by function |
